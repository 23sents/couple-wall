# Наши обои (CoupleWall)

Выбор и установка обоев (главный экран / экран блокировки) и общий рисунок для двоих, который ложится на экран блокировки обоих.

* 13 обоев, сгенерированных кодом + своё фото (кадрируется под экран)
* Пара по секретному коду (20 символов). Из кода выводятся имя темы на реле и ключ AES-256-GCM:
  реле (по умолчанию ntfy.sh) видит только шифртекст
* Штрихи нормализованы (0..1), квантуются в 16 бит, сжимаются deflate и пакуются в сообщения < 3400 символов
* Рисунок поверх обоев ставится на экран блокировки через WallpaperManager (дебаунс, не чаще раза в 8 с)
* Необязательная фоновая синхронизация (foreground service), пока приложение закрыто

Рисовать пальцем прямо на заблокированном экране Android не позволяет приложениям: рисуют в приложении, результат показывается на экране блокировки.

Ядро протокола (`core/`) — чистый Kotlin с юнит-тестами: `gradle testDebugUnitTest`.
